# Project instructions

- Prefer tidyverse style when writing R code.
- Never run git add, git commit, or git push. The user stages, commits, and pushes changes themselves.
- Preserve the user's configured Git author identity. Any future explicitly authorized commits must be authored as the user, not as an assistant or bot. Do not add assistant co-author trailers.
- This is a static HTML/CSS/JavaScript site. Preserve compatibility with GitHub Pages project URLs, including relative asset paths.
- Norwegian is the default language. Add English translations in i18n.js when changing visible text or accessibility labels.
- The contact form is a preview. Do not claim submissions are sent or stored until a backend is implemented.
